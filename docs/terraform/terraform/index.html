What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool developed by HashiCorp.

It allows you to:

  • Define infrastructure using declarative configuration files
  • Provision resources across multiple cloud platforms
  • Create, update, and destroy infrastructure safely and consistently

Terraform supports many providers, including:

  • AWS
  • Azure
  • Google Cloud Platform (GCP)
  • Kubernetes
  • Various SaaS platforms

How Terraform Works

Terraform follows a simple workflow where infrastructure is driven by code.

flowchart LR
    TF_FILES["Terraform Files (.tf)"]
    CLI["Terraform CLI"]
    PROVIDER["Provider Plugin"]
    API["Cloud API"]
    INFRA["Infrastructure Resources"]

    TF_FILES --> CLI
    CLI --> PROVIDER
    PROVIDER --> API
    API --> INFRA

Providers translate Terraform configurations into API calls that create or manage real infrastructure.

Terraform Lifecycle Phases

Terraform operations follow a well-defined execution lifecycle.

flowchart LR
    INIT[terraform init]
    VALIDATE[terraform validate]
    PLAN[terraform plan]
    APPLY[terraform apply]
    DESTROY[terraform destroy]

    INIT --> VALIDATE
    VALIDATE --> PLAN
    PLAN --> APPLY
    APPLY --> DESTROY

Phase Breakdown

  • init Initializes the working directory and downloads required providers

  • validate Checks configuration syntax and internal consistency

  • plan Displays the execution plan showing what changes Terraform will make

  • apply Creates or updates infrastructure resources

  • destroy Safely removes all resources managed by Terraform
